Click the TempleOS screen before typing. Its command line runs HolyC; commands normally end with a semicolon.

Keys worth knowing

F1Open help.
Ctrl+MOpen the Personal Menu.
Ctrl+DOpen the TempleOS file manager.
F5 in the editorRun the current file.
Esc in the editorSave and exit.
Shift+EscAbort and exit; discard editor changes.
Ctrl+TToggle plain text / DolDoc formatting.
Ctrl+R in a documentInsert or edit a sprite.

Browser Esc releases a captured mouse. Use the site's Keys strip to send Esc to TempleOS while captured.

Files and folders

Dir;List the current directory. Left-click a file to edit it; right-click to include/run it.
Cd("C:/Home");Go to your home directory.
Cd("..");Go up one directory.
DirMk("MyStuff");Create a directory.
Ed("Hello.HC");Create or edit a HolyC program.
Type("Hello.HC");Print a file's contents.
Copy("Hello.HC","Backup.HC");Copy a file. Choose a new destination name to keep existing files.
Move("Old.HC","New.HC");Rename or move a file.

A first program

Type Ed("Hello.HC");, enter this code, then press F5:

U0 Hello()
{
  "Hello, TempleOS!\n";
}

Hello;

After saving, run it again with #include "Hello". HolyC compiles and executes the file immediately. Re-including a file reruns its top-level code.
